# o scripts/ci/verificar-regras-go.py deixa passar, cada um com o porquê. Sem a exceção aqui, o job "Go" falha.
#
# Uma por linha, separada por " | ": regra | arquivo (a partir de src/backend-go) | a linha do código, sem os espaços das
# pontas e sem o comentário | por que pode. A regra é float64 (que pega também Float64(), ParseFloat e FormatFloat),
# time.Now ou time.Sleep (o de teste; dentro do synctest.Test ele passa sozinho). É pelo texto da linha, e não pelo
# número: a linha mudou, a exceção para de valer e a regra volta a falhar para alguém olhar de novo. Exceção que não casa
# com nenhuma linha também falha. Só entra aqui o que foi conferido à mão; na dúvida, troque o código.
#
# float64 é só para o que o C# também calcula em double e que não é dinheiro, quantidade nem taxa: dinheiro é
# tipos.Decimal. time.Now só para hora de sistema (processo, certificado, duração), nunca data de negócio.
